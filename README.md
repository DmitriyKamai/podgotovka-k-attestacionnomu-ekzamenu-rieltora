# Бот подготовки к аттестационному экзамену риэлтера

Telegram-бот на **OpenCode Go** (OpenAI-совместимый эндпоинт). У каждого пользователя — своя история и прогресс; общая база знаний (НПА + ответы) только читается.

## Что умеет
- **/exam** — режим экзамена: бот задаёт вопрос, вы отвечаете, он проверяет по эталонному ответу (оценка 2–5).
- **/list** — выбрать раздел Программы, затем вопрос из раздела.
- **/q 58** — сразу открыть вопрос по номеру Программы.
- **/next** — следующий вопрос.
- **/ask <вопрос>** — вопрос по НПА (только для администратора: эталонный ответ + полные тексты статей).
- **Голосовые сообщения** — распознаются через Yandex SpeechKit и проверяются так же, как текст.
- **/stop**, **/reset**; для администратора — **/stats**, **/users**, **/check**, **/diag**, **/grant**, **/settings**, **/id**.
- **Мотивация**: при оценке 3–5 модель генерирует одну короткую строку `💬` по конкретике ответа (что получилось / чего не хватило) — без лести и общих похвал. При 2 и ниже реакции нет. Если модель её не выдала, срабатывает запасная фраза.

## Требования
- Python 3.10+
- Токен бота от [@BotFather](https://t.me/BotFather)
- API-ключ **OpenCode Go** (Console → подписка Go/Go Plus → скопировать API key)

## Установка
```bash
cd bot
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка
1. Скопируйте `.env.example` в `.env`.
2. Заполните:
   - `BOT_TOKEN` — токен от BotFather;
   - `GO_API_KEY` — ключ OpenCode Go;
   - `ALLOWED_IDS` — Telegram ID людей через запятую (пусто = доступ всем, не рекомендуется).
3. Для голосовых сообщений (необязательно):
   - в Yandex Cloud создайте каталог (folder);
   - создайте сервисный аккаунт с ролью `ai.speechkit-stt.user`;
   - выпустите для него API-ключ;
   - впишите в `.env`: `YANDEX_API_KEY` (ключ) и `YANDEX_FOLDER_ID` (ID каталога).
4. Запустите бота: `python main.py` (или `run.bat`).
5. Напишите боту `/start` — он покажет ваш ID, добавьте его в `ALLOWED_IDS` и перезапустите.

### Голосовые сообщения
- Синхронное распознавание Yandex принимает до **30 секунд** и 1 МБ.
- Более длинные голосовые автоматически режутся на части через `ffmpeg` (входит в `imageio-ffmpeg`) и распознаются по частям.
- Если `YANDEX_API_KEY` не задан, бот вежливо скажет, что голосовые не настроены, и продолжит работать с текстом.
- `YANDEX_FOLDER_ID` указывайте, если роль `ai.speechkit-stt.user` выдана на конкретный каталог: без него Yandex может взять другой каталог и вернуть `401 PermissionDenied`.
- После выдачи роли IAM может расходиться несколько минут — временные 401 проходят сами.

## Защита от спама
- **Кулдаун** между проверяемыми ответами: `RATE_LIMIT_SECONDS` (по умолчанию 6 сек).
- **Часовой лимит** запросов к модели: `RATE_LIMIT_PER_HOUR` (60).
- **Длина текста**: не более `MAX_INPUT_CHARS` (4000 символов).
- **Длина голосового**: не более `MAX_VOICE_SECONDS` (120 сек).
- **Общий лимит одновременных запросов к LLM**: `MAX_CONCURRENT_LLM` (4) — защищает от перегрузки и слива квоты.
- **Бан**: `/ban <id>` и `/unban <id>` (админ). Забаненный не получает ответов.
- **Белый список**: `ALLOWED_IDS` — если задан, бот отвечает только перечисленным ID. Самая надёжная защита для узкого круга.

Промпт проверки отдельно оговаривает, что текст ответа — данные, а не инструкции (защита от prompt injection).

## Данные
Папка `knowledge/`:
- `answers.md` — вопросы с ответами (по ней работает режим экзамена);
- `contracts.md` — разбор договоров (для /ask);
- `npa/*.txt` — тексты НПА (для /ask).

Вопросы в `/exam` и `/list` идут по возрастанию номеров Программы; тематические вопросы без номера — в конце. `/q` принимает номер пункта Программы (например, `/q 43`).

Чтобы обновить базу — замените файлы и перезапустите бота.

### База данных: внешняя Postgres

Бот работает **только с внешней Postgres** — локальная SQLite удалена. Нужен проект на **Neon** (neon.tech) или Supabase; строка подключения задаётся в `DATABASE_URL`.

1. Зарегистрируйтесь на Neon и создайте проект (регион — ближайший, например EU).
2. Скопируйте **connection string** вида:
   `postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`
3. Пропишите его в переменных окружения хостинга:
   `DATABASE_URL=postgresql://...`
4. Перезапустите бота. Таблицы создадутся автоматически, данные будут храниться во внешней базе и переживут любой передеплой.

Без `DATABASE_URL` бот не запустится — это обязательная настройка. Проверить режим: `/diag` показывает «БД: внешняя Postgres».

Соединения с Neon восстанавливаются автоматически: пул проверяет соединение перед запросом, пересоздаёт простаивающие и повторяет операцию при обрыве (`AdminShutdown`, `ConnectionDoesNotExist`). Пользователь видит сообщение «База данных временно недоступна» только если база недоступна дольше нескольких секунд.

Для работы с Postgres нужны пакеты `psycopg[binary]` и `psycopg_pool` (уже в `requirements.txt`).

## Администратор
ID администратора задан в `config.py` (`ADMIN_ID = 7930922924`). Только ему доступны:
- **`/stats`** — сколько ответов сделал каждый пользователь и его средний балл;
- **`/users`** (кнопка «👥 Пользователи») — список всех: доступ (платно/бесплатно/демо), сколько дней осталось, число ответов и средний балл;
- **`/diag`** — пути к базе, число вопросов и файлы;
- **`/check`** — проверка базы ответов (пустые, короткие, дубли, отсутствующие статьи);
- **`/grant <id> [дней]`** (или кнопка «➕ Выдать доступ») — выдать доступ по Telegram ID: `123456789` — навсегда, `123456789 30` — на 30 дней;
- **`/settings`** (кнопка «⚙️ Настройки») — цена, демо-лимит, включение платного режима;
- **`/id`** — свой Telegram ID.

Статистика начинает считаться с момента запуска этой версии: старые проверенные ответы в неё не попадают.

## Платный доступ (Telegram Stars)
- **По умолчанию включён**: 500 ⭐ за 30 дней, 5 бесплатных вопросов.
- **Меняется админом в боте**: кнопка **«⚙️ Настройки»** (или `/settings`) — цена, число бесплатных вопросов, включение/выключение платного режима. Значения хранятся в Postgres (`settings`) и переживают перезапуск.
- **Срок подписки — 30 дней**, фиксирован: Telegram для звёздных подписок допускает только 30 дней (2592000 секунд).
- **Бесплатно (демо)**: первые N вопросов в режиме экзамена и через выбор из списка.
- **«Спросить по НПА»** — только для администратора (в общем меню и для подписчиков недоступно).
- Администратор и пользователи, которым админ выдал доступ через `/grant`, оплату не проходят. В `.env` ничего настраивать не нужно.

Чтобы бот принимал оплату звёздами, **ничего включать в BotFather не нужно**: для цифровых товаров достаточно `currency="XTR"` и пустого `provider_token`. Экран «Telegram Stars» с кнопкой «Learn More» — информационный, переключателя там нет. Вывод заработанных звёзд — через Fragment.

Для соответствия правилам Telegram добавлены команды **`/terms`** (условия подписки), **`/support`** и **`/paysupport`** (поддержка по оплате). Контакт для всех случаев — **@exam_admin**.

После успешной оплаты бот получает `successful_payment` и продлевает доступ до `subscription_expiration_date`; каждое списание пишется в таблицу `payments`.

> Папка называется `knowledge`, а не `data`: некоторые хостинги автоматически перезаписывают папку `data` при деплое. Файлы называются латиницей (`answers.md`, `contracts.md`), чтобы не зависеть от кодировки имён на Linux-хостинге.

## Как устроено
- `kb.py` — загрузка документов, нарезка на фрагменты, поиск BM25, парсинг вопросов.
- `llm.py` — запрос к OpenCode Go (`/inference/go/openai/v1/chat/completions`), заголовки `Authorization`, `User-Agent`, `x-opencode-session` (по одному на пользователя).
- `stt.py` — распознавание голосовых через Yandex SpeechKit (OGG/Opus; длинные — через ffmpeg).
- `db.py` — Postgres: пользователи, режим, номер вопроса, история, ответы, платежи (изолированно по `user_id`).
- `main.py` — Telegram-хендлеры.

## Важно про OpenCode Go
- Go предназначен для OpenCode и других coding-агентов; трафик мониторится. Для «не-codding» нагрузки возможны ограничения — если начнутся 401/403/429, проверьте подписку и лимиты в Console.
- Ключ храните только на сервере, не публикуйте.
- Модель по умолчанию: `deepseek-v4.1-flash` (можно сменить `MODEL` в `.env`).
