# Бот подготовки к аттестационному экзамену риэлтера

Telegram-бот на **OpenCode Go** (OpenAI-совместимый эндпоинт). У каждого пользователя — своя история и прогресс; общая база знаний (НПА + ответы) только читается.

## Что умеет
- **/exam** — режим экзамена: бот задаёт вопрос, вы отвечаете, он проверяет по эталону и чек-листу (оценка 2–5).
- **/next** — следующий вопрос.
- **/ask <вопрос>** — вопрос по НПА (поиск по текстам актов, ответ со ссылками).
- **Голосовые сообщения** — распознаются через Yandex SpeechKit и проверяются так же, как текст.
- **/stop**, **/reset**, **/id**.

## Требования
- Python 3.10+
- Токен бота от [@BotFather](https://t.me/BotFather)
- API-ключ **OpenCode Go** (Console → подписка Go/Go Plus → скопировать API key)

## Установка
```bash
cd bot
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка
1. Скопируйте `.env.example` в `.env`.
2. Заполните:
   - `BOT_TOKEN` — токен от BotFather;
   - `GO_API_KEY` — ключ OpenCode Go;
   - `ALLOWED_IDS` — Telegram ID людей через запятую (пусто = доступ всем, не рекомендуется).
3. Для голосовых сообщений (необязательно):
   - в Yandex Cloud создайте каталог (folder);
   - создайте сервисный аккаунт с ролью `ai.speechkit-stt.user`;
   - выпустите для него API-ключ;
   - впишите в `.env`: `YANDEX_API_KEY` (ключ) и `YANDEX_FOLDER_ID` (ID каталога).
4. Запустите бота: `python main.py` (или `run.bat`).
5. Напишите боту `/start` — он покажет ваш ID, добавьте его в `ALLOWED_IDS` и перезапустите.

### Голосовые сообщения
- Синхронное распознавание Yandex принимает до **30 секунд** и 1 МБ.
- Более длинные голосовые автоматически режутся на части через `ffmpeg` (входит в `imageio-ffmpeg`) и распознаются по частям.
- Если `YANDEX_API_KEY` не задан, бот вежливо скажет, что голосовые не настроены, и продолжит работать с текстом.
- `YANDEX_FOLDER_ID` указывайте, если роль `ai.speechkit-stt.user` выдана на конкретный каталог: без него Yandex может взять другой каталог и вернуть `401 PermissionDenied`.
- После выдачи роли IAM может расходиться несколько минут — временные 401 проходят сами.

## Данные
Папка `knowledge/`:
- `answers.md` — вопросы с ответами (по ней работает режим экзамена);
- `contracts.md` — разбор договоров (для /ask);
- `npa/*.txt` — тексты НПА (для /ask).

Чтобы обновить базу — замените файлы и перезапустите бота.

> Папка называется `knowledge`, а не `data`: некоторые хостинги автоматически перезаписывают папку `data` при деплое. Файлы называются латиницей (`answers.md`, `contracts.md`), чтобы не зависеть от кодировки имён на Linux-хостинге.

## Как устроено
- `kb.py` — загрузка документов, нарезка на фрагменты, поиск BM25, парсинг вопросов.
- `llm.py` — запрос к OpenCode Go (`/inference/go/openai/v1/chat/completions`), заголовки `Authorization`, `User-Agent`, `x-opencode-session` (по одному на пользователя).
- `stt.py` — распознавание голосовых через Yandex SpeechKit (OGG/Opus; длинные — через ffmpeg).
- `db.py` — SQLite: пользователи, режим, номер вопроса, история (изолированно по `user_id`).
- `main.py` — Telegram-хендлеры.

## Важно про OpenCode Go
- Go предназначен для OpenCode и других coding-агентов; трафик мониторится. Для «не-codding» нагрузки возможны ограничения — если начнутся 401/403/429, проверьте подписку и лимиты в Console.
- Ключ храните только на сервере, не публикуйте.
- Модель по умолчанию: `deepseek-v4.1-flash` (можно сменить `MODEL` в `.env`).
